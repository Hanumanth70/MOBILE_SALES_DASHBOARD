# MOBILE_SALES_DASHBOARD
Mobile Sales Data Analysis explores sales trends and customer behavior using Python and Power BI.
The dataset includes transactions with details like brand, model, units sold, and customer demographics.
Python is used for cleaning, transforming, and visualizing monthly sales, top brands, and models.
Power BI provides an interactive dashboard for dynamic filtering and business insights.
This project showcases skills in data wrangling, time series analysis, and dashboard design.
